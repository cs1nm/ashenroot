# Shadowgrove — мультиплеер

## Режимы

Сетевая архитектура сохраняет одиночную игру и добавляет ENet-сессии:

- обычная офлайн-игра;
- listen-server из Android/desktop-клиента;
- выделенный headless-сервер на Windows/Linux/VPS;
- подключение через интернет по IP или без интернета через хот-спот;
- до 8 игроков;
- переключаемые владельцем PvE/PvP;
- пароль сервера;
- автоматическая передача сжатого мира при подключении.

ENet использует **UDP**. Для интернет-сервера нужно открыть выбранный UDP-порт в роутере и firewall (по умолчанию `24567`). У мобильных операторов часто используется CGNAT, поэтому сервер на Android обычно доступен через хот-спот, но не из интернета. Для постоянного интернет-сервера надёжнее ПК/VPS с публичным адресом.

## Сервер из игры

1. Создай и хотя бы один раз открой одиночный мир.
2. На главном экране нажми **MULTIPLAYER**.
3. Выбери мир, имя сервера, UDP-порт и при необходимости пароль.
4. Выбери PvE/PvP и нажми **HOST WORLD**.
5. Остальные игроки вводят IP, порт и пароль через **JOIN IP**.

Для игры без интернета включи хот-спот на телефоне, подключи к нему остальные устройства и используй локальный IP хоста. Поиск серверов в локальной сети не используется.

Владелец может переключать PvE/PvP во время игры из меню паузы. Там же отображается список участников и кнопка **KICK** для каждого гостя. Обычная кнопка **TO MENU** корректно отключает клиента или останавливает listen-server.

## Выделенный сервер

Проект можно запустить в Godot 4.7.1 без графики:

```bash
Godot_v4.7.1-stable_linux.x86_64 \
  --headless --path /path/to/ashenroot -- \
  --dedicated \
  --world=0 \
  --port=24567 \
  --name="My Shadowgrove" \
  --password="optional-password" \
  --pvp=false
```

Также есть оболочки `server/start_server.sh` и `server/start_server.bat`. Путь к Godot задаётся переменной `GODOT_BIN`.

Аргументы после второго `--`:

- `--world=N` — слот серверного мира, по умолчанию `0`;
- `--port=N` — UDP-порт, по умолчанию `24567`;
- `--name=TEXT` — имя сервера;
- `--password=TEXT` — необязательный пароль;
- `--pvp=true|false` — режим PvP;
- `--import=/path/world.json` — проверить и импортировать мир перед запуском;
- `--export=/path/world.json` — обновлять внешнюю копию мира при автосохранении.

Успешный запуск выводит:

```text
DEDICATED_SERVER_READY port=24567 world=0 mode=pve
```

## Импорт и экспорт мира

Кнопка **EXPORT** на сетевом экране копирует выбранный мир в Downloads как `shadowgrove_world_N.json`, если платформа разрешает запись, иначе используется `user://exports`.

Выделенный сервер принимает этот файл через `--import`. Параметр `--export` создаёт обновляемую копию. После остановки сервера положи её в Downloads под тем же именем, выбери исходный слот в игре и нажми **IMPORT**. Нельзя заменять сейв во время работы сервера; перед импортом в клиенте нужно отключиться от сети.

## Модель авторитета

- Сервер управляет врагами, их здоровьем, снарядами и общим состоянием мира.
- Клиент предсказывает своё движение и отправляет ограниченный по частоте state stream.
- Положение других игроков сглаживается между пакетами.
- Враги выбирают ближайшего подключённого игрока, а спавны распределяются между участниками.
- Добыча и установка блоков выполняются сервером с проверкой расстояния, инструмента и ресурсов.
- Общий лут, крафт, расходники и содержимое сундуков изменяются только сервером.
- Открытый сундук обновляется у всех игроков, которые одновременно его просматривают.
- Сервер проверяет экипировку, допустимый урон, снаряды и PvP-удары.
- Здоровье, смерть, возрождение и восстановление гостя подтверждаются сервером.
- Handshake проверяет версию протокола, пароль, лимит игроков, имена и постоянный идентификатор профиля.

## Профили гостей

При первой сетевой игре устройство создаёт локальный случайный идентификатор. В каждом мире хоста по нему сохраняются инвентарь, панель быстрого доступа, экипировка, класс, здоровье, позиция и точка возрождения гостя. Поэтому повторное подключение с того же устройства продолжает предыдущий прогресс, даже если игрок поменял отображаемое имя.

Профили входят в сейв мира и в `--export`. Переустановка игры или очистка её данных создаст новый идентификатор и новый профиль. Одновременное подключение одного профиля с двух копий клиента запрещено.

Публичный браузер серверов пока отложен. Для него потребуется отдельно развёрнутый HTTPS master-server; прямое подключение и хот-спот от него не зависят.
