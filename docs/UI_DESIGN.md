# Shadowgrove — UI Design Spec (v3, FINAL — светлый Terraria-стиль)

> Финальный интерфейс в светлом пиксель-арте (в духе Terraria):
> тёплые деревянные панели, пергаментные фоны, тёмный читаемый текст,
> яркие золотые/оранжевые акценты. Единая палитра, чёткие 9-slice рамки,
> аккуратная компоновка. Этот документ — источник правды. Не менять стиль
> без обновления файла.

## 2. Шрифты
- Заголовки: Press Start 2P (ps2p.ttf), размеры 16/13/9 — цвет `gold_text`.
- Текст: системный fallback, размеры 10/9/8 — цвет `text_main`.
- На тёмных бэкдропах (миникарта, тосты) — `text_light`.

## 3. Компоненты (9-slice, margin 6–10)

### 3.1 frame.png (панель — тёмное дерево)
- Фон `bg_panel` (тёмное дерево), внешняя рамка 2px `border`, внутренний блик
  1px `border_hi`. Углы — скруглённые пиксельные.
- «Деревянные» доски: 2–3 тонкие горизонтальные линии `WOOD_LINE` внутри.
- margin 8.

### 3.2 frame_inner.png / frame_inner_accent.png
- Как frame, но фон `bg_panel2`; accent — золотая линия сверху 1px `accent`.

### 3.3 button.png / button_hover.png / button_pressed.png
- Высота ~28px, фон `bg_panel2`, рамка 1px `border`.
- hover: рамка `border_hi` + фон `#e8cf9a`.
- pressed: фон `accent_deep`, текст тёмный.
- Левый край: 3px янтарная «таб»-полоска.

### 3.4 slot.png / slot_selected.png (ячейки)
- Квадрат ~54px, фон `bg_inner` (светлый пергамент), рамка 1px `border`,
  внутренняя тень 1px.
- selected: рамка 2px `accent` + янтарные уголки + лёгкое свечение.

### 3.5 boss_bar.png
- Ширина ~520px, фон `hp_bg` (тёмно-красный), рамка `border`, череп слева.

### 3.6 heart_full / half / empty
- 16×14: полное = ярко-красное с бликом, половина = левая половина красная,
  пустое = тёмный контур на светлом фоне.

### 3.7 Иконки статусов (armor, bubble, thermo, sun)
- 14×14: тёмный контур `border` + цветная заливка + блик.

### 3.8 lens_ring.png (миникарта)
- Кольцо 2px `border`, золотые насечки N/E/S/W, фон внутри `bg_inner`.

## 4. Компоновка (НОВАЯ, финальная)

- **Виталы (слева сверху):** светлая панель `frame.png`, внутри —
  ряд сердец, чип DEF, воздух/температура, статусы. Текст тёмный.
- **Миникарта (справа сверху):** круглый светлый «линзовый» циферблат,
  под ним время/биом.
- **Хотбар (снизу по центру):** светлые слоты `bg_inner` на деревянной
  подложке `frame_inner.png`, активный слот с янтарной рамкой.
- **Тосты (сверху по центру):** тёмный бэкдроп `bg_deep` @90% с янтарной
  рамкой (читается поверх светлого мира).
- **Панели (инвентарь/крафт/журнал):** светлые, центрированные,
  бэкдроп `bg_deep` @45%.
- **Мобильное:** левый стик (светлый), справа JUMP/ATK/GRAPPLE (тёмные
  полупрозрачные круги с золотыми иконками — контраст на светлом фоне).
- **Диалог NPC (выбор пути):** светлая панель, портрет Странника,
  кнопки SCIENCE/MAGIC с иконками ракеты/сферы.

## 5. Правила
- Панели тёмно-деревянные — текст кремовый (`text_main`/`gold_text`).
- Бэкдропы/тосты — тёмные, текст светлый (`text_light`).
- Выделение всегда янтарное `accent`.
- Никаких размытых градиентов — только 1px ступени и 2px тени.
- Опасное красное, успех зелёное.
