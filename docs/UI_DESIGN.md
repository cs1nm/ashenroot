# Shadowgrove — UI Design Spec (v2, final)

> Финальный интерфейс в улучшенном пиксель-арте (Terraria-дух).
> Цель: единая палитра, чёткие 9-slice рамки, читаемые кнопки,
> аккуратная компоновка. Этот документ — источник правды для всех
> UI-текстур и цветов. Не менять стиль без обновления этого файла.

## 2. Шрифты
- Заголовки: **Press Start 2P** (ps2p.ttf), размеры 16/13/9.
- Текст: системный fallback (уже подключён), размеры 10/9/8.
- Все кнопки/панели используют `ui_pixel_font` для заголовков.

## 3. Компоненты (9-slice, margin 6–10)

### 3.1 frame.png (панель)
- Внешняя рамка 2px `border`, внутренний скос 1px `border_hi` снизу/справа,
  фон `bg_panel` (96% непрозрачность). Углы — скруглённые «пиксельные» (срезанные).
- margin 8.

### 3.2 frame_inner.png / frame_inner_accent.png
- Как frame, но фон `bg_panel2` (внутренние блоки); accent-вариант с янтарной
  линией сверху 1px.

### 3.3 button.png / button_hover.png / button_pressed.png
- Высота ~28px, рамка 1px `border`, фон `bg_panel2`.
- hover: рамка `border_hi` + фон чуть светлее `#202a3a`.
- pressed: фон `accent_dim` (залитый), текст тёмный.
- Левый край: 3px янтарная «таб»-полоска (для кнопок-действий).

### 3.4 slot.png / slot_selected.png (ячейки инвентаря/хотбара)
- Квадрат ~54px, фон `bg_deep`, рамка 1px `border`, внутренняя тень.
- selected: рамка 2px `accent` + янтарные уголки.

### 3.5 boss_bar.png
- Ширина ~520px, фон `hp_bg`, рамка `border`; внутри пусто (заполняет ProgressBar).

### 3.6 heart_full / heart_half / heart_empty
- 16×14 пиксельные сердечки: полное = красное с бликом, половина = левая
  половина красная, пустое = тёмный контур.

### 3.7 Иконки статусов (armor, bubble, thermo, sun)
- 14×14 пиксельные, единый стиль: тёмный контур + цветная заливка + блик.

### 3.8 lens_ring.png (миникарта)
- Кольцо 2px `border_hi` + янтарные насечки (север/восток/юг/запад).

## 4. Компоновка (не меняется в этом пассе)
- HUD: виталы сверху-слева (сердца, DEF, воздух, темп), миникарта сверху-справа,
  хотбар снизу-по-центру, тосты сверху-по-центру.
- Панели: инвентарь/крафт/журнал — по центру, бэкдроп `#0b0e13` при 30%.
- Мобильное: левый стик, справа JUMP/ATK/GRAPPLE, верх — INV/DEV/PAUSE/BUILD.

## 5. Правила
- Никаких размытых градиентов — только пиксельные ступени (1px).
- Тени: 2px вниз-вправо, `#000` при 35%.
- Выделение всегда янтарное (`accent`).
- Опасное всегда красное (`hp`/`danger`), успех — зелёное (`ok`).
