# Концепт интерфейса — «Пепельный Архив» (Ash en Archive)

Интерактивный мокап нового интерфейса для Ashen Roots. Полностью другой стиль,
не связанный с текущим «компасным» HUD: вместо зелёных коробок — тёмный
обсидиан, тлеющий янтарь (ember) и золото памяти.

## Как смотреть

### Картинки (без браузера и сервера)

Готовые рендеры экранов лежат в `ui_concept/preview/`:

| Файл | Что на нём |
|---|---|
| `overview.png` | все 4 экрана одним листом |
| `gameplay.png` | HUD: кольцо здоровья, миникарта-линза, хотбар |
| `gameplay_night_boss.png` | ночь + босс-бар |
| `inventory.png` | инвентарь «Архив выжившего» + горн рецептов |
| `map.png` | карта мира с туманом войны |
| `journal.png` | журнал «Хроники» (бестиарий) |

### Интерактивный мокап (браузер)

Открой `ui_concept/index.html` в браузере (или запусти из корня репозитория):

```bash
python3 -m http.server 8310
# затем http://localhost:8310/ui_concept/
```

Сервер нужен, чтобы мокап брал настоящие текстуры из `assets/textures/`.

Перерендер картинок: `python3 ui_concept/render_preview.py` (нужен Pillow; шрифты:
Press Start 2P в `/tmp/fonts/ps2p.ttf`, DejaVu — системный).

## Экраны и управление

| Клавиша | Что делает |
|---|---|
| `Enter` | закрыть интро, показать HUD |
| `Tab` / `I` | инвентарь (Рюкзак · Горн рецептов) |
| `M` | карта мира с туманом войны |
| `J` | журнал (Бестиарий · Материалы · Рецепты) |
| `1–5` | выбор слота хотбара |
| `N` | день/ночь (демо) |
| `B` | босс-бар (демо) |
| `W` | подводная дымка + кольцо воздуха (демо) |
| `Esc` | закрыть окно |

Кнопки демо — в левом нижнем углу.

## Что в концепте

- **HUD без панелей**: здоровье-кольцо (свечение ember), бронёвый чип,
  статус-эффекты с таймерами, время суток и биом по центру, миникарта-линза
  (круглое окно в карту мира), парящий хотбар с подсветкой выбранного слота.
- **Инвентарь «Архив выжившего»**: живой спрайт героя (из игры), слоты
  снаряжения вокруг него, сетка 30 слотов с реальными иконками предметов,
  панель «Горн рецептов» с фильтром по станции и чипами стоимости (есть/нет).
- **Карта**: та же миникарта-линза в полный экран, туман войны вокруг игрока,
  легенда биомов.
- **Журнал «Хроники»**: бестиарий с реальными спрайтами врагов (idle-кадры из
  анимационных паков), материалы, рецепты.
- Все иконки и спрайты — **настоящие ассеты игры**, мокап не содержит
  нарисованных от балды картинок (кроме двух фонов-заглушек, их можно заменить
  реальными скриншотами мира).

## Как это переносится в Godot

Весь визуал реализуем на `StyleBoxFlat` / `CanvasItem` без внешних текстур:
кольцо HP — `draw_arc`, линза-миникарта — круглая маска `TextureRect`,
хотбар — те же `Button`, но со скруглением и свечением (`shadow`/`glow`).
Шрифты: `Press Start 2P` (цифры/заголовки) + моноширинный с кириллицей для
текста. При желании можно собрать тему в `Theme` и заменить `_setup_hud()`.
